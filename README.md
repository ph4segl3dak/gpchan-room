# 지피짱의 쉬는 시간

지피짱과 잠깐 쉬어 가는 작은 3D 방입니다. 머리를 쓰다듬고, 쿠키를 건네고, 손인사·하트·브이 포즈를 감상할 수 있습니다.

[방에 들어가기](https://ph4segl3dak.github.io/gpchan-room/)

## 조작

- 머리 위를 드래그하면 쓰다듬습니다. 아래 버튼으로도 반응을 재생할 수 있습니다.
- 쿠키를 클릭하거나 입 가까이 끌어다 놓습니다.
- 하트·브이는 다시 누르거나 다른 반응을 선택할 때까지 유지됩니다.
- 빈 배경을 드래그해 회전하고, 휠이나 가까이·전신 버튼으로 구도를 바꿉니다.
- 추억 네 가지는 이 브라우저에 저장됩니다. 카드를 누르면 다시 재생합니다.
- 사진 모드에서 UI 없는 PNG를 저장할 수 있습니다.
- `1`–`5`: 반응, `P`: 사진 모드, 사진 모드에서 `Space`: 저장, `Esc`: 닫기·포즈 해제, `0`: 처음 구도. 터치와 키보드 버튼 조작을 지원합니다.
- 소리는 기본 꺼짐입니다. 음표 버튼으로 짧은 합성 효과음을 켭니다.

빌드 과정이나 외부 CDN 없이 정적 HTTP 서버에서 실행됩니다. 모든 라이브러리와 모델은 프로젝트에 포함됩니다.
