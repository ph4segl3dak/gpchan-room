# 지피짱의 쉬는 시간

지피짱과 잠깐 쉬어 가는 작은 3D 방입니다. 머리를 쓰다듬고, 쿠키를 건네고, 손인사·하트·브이 포즈와 세 가지 춤을 감상하거나 방 안을 걸어 다닐 수 있습니다.

[방에 들어가기](https://ph4segl3dak.github.io/gpchan-room/)

## 조작

- 좌하단 이동 핸들을 끌거나 `WASD` / 방향키로 걷습니다. 손을 떼면 부드럽게 멈추며 가구와 방 경계를 지나가지 않습니다.
- 춤 선택에서 OMG, After LIKE, Hype Boy를 고르고 ▶를 누릅니다. ■로 중지합니다. 음악은 포함하지 않습니다.
- 걷기나 다른 반응을 시작하면 춤이 자연스럽게 끝납니다. 춤은 전신 구도로 재생하며 끝나면 이전 구도로 돌아옵니다.
- 머리 위를 드래그하면 쓰다듬습니다. 아래 버튼으로도 반응을 재생할 수 있습니다.
- 쿠키를 클릭하거나 입 가까이 끌어다 놓습니다. 하트·브이는 다시 누르거나 다른 반응을 고를 때까지 유지됩니다.
- 빈 배경을 드래그해 시점을 바꿉니다. 모바일에서는 한 손가락으로 이동하면서 다른 손가락으로 시점을 조작할 수 있습니다.
- `제자리로` 또는 `0`: 위치·포즈·구도 초기화.
- 추억 네 가지는 이 브라우저에 저장됩니다. 사진 모드에서는 UI 없는 PNG를 저장합니다.
- `1`–`5`: 반응, `P`: 사진 모드, 사진 모드에서 `Space`: 저장, `Esc`: 닫기·포즈 해제.
- 소리는 기본 꺼짐이며 음표 버튼으로 짧은 합성 효과음을 켭니다.

빌드 과정이나 외부 CDN 없이 정적 HTTP 서버에서 실행됩니다. WebGL이 필요합니다.
